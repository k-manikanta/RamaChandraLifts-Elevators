## 🚀 How to Build

### Option 1: Automatic (Easiest)
**Windows:**
```
Double-click setup.bat
```

**Mac/Linux:**
```bash
bash setup.sh
```

This automatically:
1. Checks for Node.js
2. Installs dependencies
3. Builds CSS
4. Shows success message

### Option 2: Manual

**Step 1:** Install dependencies
```bash
npm install
```

**Step 2:** Build CSS
```bash
npm run build
```

**Step 3:** Open website
```
Open index.html in browser
```

That's it! Your website now uses local CSS instead of CDN.

## 🔄 CSS Generation Process

```
src/input.css (Tailwind directives)
        ↓
   [Tailwind CLI]
        ↓
   Scans all HTML files for classes
        ↓
   Only includes used classes
        ↓
css/tailwind.css (optimized output)
```

**Result:** Only CSS you actually use! Unused styles removed automatically.

## ⚙️ Customization

### Change Colors
Edit `tailwind.config.js`:
```javascript
theme: {
  extend: {
    colors: {
      'gold': '#d4a853',
      'dark': '#0a1628',
    }
  }
}
```

### Add Custom CSS
Edit `src/input.css`:
```css
@layer components {
  .my-custom-button {
    @apply px-4 py-2 bg-gold text-dark rounded-lg;
  }
}
```

### Update Build
```bash
npm run build
```

## 🌐 Deployment

### Netlify (Easiest)
1. Push to GitHub
2. Connect to Netlify
3. Build command: `npm run build`
4. Publish directory: `.`
5. Deploy!

### GitHub Pages
1. Run: `npm run minify`
2. Commit `css/tailwind.css`
3. Push to GitHub
4. Enable Pages
5. Done!

### Any Web Host
1. Run: `npm run minify`
2. Upload all files (including `css/tailwind.css`)
3. Done!

## 🐛 Troubleshooting

| Issue | Solution |
|-------|----------|
| Node.js not found | Download from https://nodejs.org/ |
| CSS not generated | Run `npm run build` again |
| Changes not showing | Delete `css/tailwind.css` and rebuild |
| File too large | Use `npm run minify` |
| npm install fails | Delete `node_modules` folder and retry |
